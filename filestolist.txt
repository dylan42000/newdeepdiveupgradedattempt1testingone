Shared / Project-level files (important context):

- AUTOPILOTUPGRADEBIBLE

- any `.env` or config files (only share non-sensitive or sanitized copies)

Notes and suggestions:
- Provide full source folders (`src/`, `public/`, `electron/`, `android/app/src/`) rather than just individual files so the AI can infer structure and wiring.
- Include build/configuration files (package.json, tsconfig.json, vite.config.ts, build.gradle, electron-builder.json) so the AI understands build & packaging steps.
- Avoid uploading large build artifacts (e.g. `android/app/build/`, `release/win-unpacked/`) unless needed; share config files instead.
- Sanitize or omit secret files (keystore, passwords, local SDK paths) unless you intend the AI to have them.

If you want a minimal checklist file (one-line per path) for automated upload, use the items above and expand any `/**` entries to the full file lists in those folders.
