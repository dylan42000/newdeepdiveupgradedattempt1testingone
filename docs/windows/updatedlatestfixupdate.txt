1. THE PARSER PROBLEM — ROOT CAUSE ANALYSIS
Why the Parser Has Always Failed
The credit report parser has never worked reliably because it was built around a single optimistic assumption: that the text fed to the AI would be clean, structured, and consistent. Credit reports are none of those things. Here is the complete diagnosis of every failure mode:

Failure Mode 1: PDF Text Extraction Produces Garbage
pdfjs-dist extracts text from PDFs, but credit report PDFs are notoriously complex:

Multi-column layouts — text is extracted column by column, not left-to-right. Account name, balance, and status end up on completely different lines in the extracted text with no relationship to each other.
Scanned PDFs — many credit reports are scanned images embedded in a PDF. pdfjs-dist extracts zero text from these because there is no text layer — just image data.
Character encoding artifacts — ligatures (ﬁ instead of fi), hyphenation across page breaks, smart quotes, bullet points as Unicode characters, all produce garbage characters in the extracted text.
Table formatting lost — credit report accounts are in tables. When the table is flattened to text, the column alignment disappears entirely. A row like Capital One | $3,400 | Charge-Off | 2021-03-01 becomes Capital One $3,400 Charge-Off 2021-03-01 with no guaranteed delimiter.
Header/footer repetition — page headers and footers repeat on every page, polluting the extracted text with duplicate bureau names, page numbers, and consumer identity info.
Text ordering by Y-coordinate — pdfjs-dist orders text by Y position on the page. In a two-column credit report, this means account items from both columns are interleaved with each other.
Result: Even perfect AI cannot parse garbage input. The parser fails before AI is even called.

Failure Mode 2: Paste Input Is Corrupted Before AI Sees It
When users copy-paste from:

Adobe Acrobat: Produces rich text with special characters, em-dashes, and no standard delimiters.
Chrome PDF viewer: Loses column spacing; account tables become single-line blobs.
AnnualCreditReport.com: HTML is copy-pasted as raw HTML with <div> tags and CSS class names mixed into the text.
Edge PDF viewer: Produces text with \r\n Windows line endings that React's onChange normalizes to \n, losing paragraph structure.
The renderer's textarea or input component then runs this through React's synthetic event system which applies its own normalization, further corrupting the input.

Result: The text that reaches aiRouter.ts is completely different from what was on screen.

Failure Mode 3: AI Prompt Is Too Generic
The current AI prompt says something like "parse this credit report and return the accounts." This gives the AI no:

Schema to conform to
Knowledge of which bureau format this is
Field extraction priorities
Error handling instructions
Output format requirements
When the AI gets confused by garbled input, it either returns nothing, returns a hallucination, or returns a partial result that the type system then silently discards.

Result: Zero items returned with no actionable error message.

Failure Mode 4: No Fallback When AI Returns Zero Items
The current code path: AI returns zero items → show error message → user is stuck.

There is no:

Regex-based fallback parser
Manual entry option auto-prompted
Diagnostic information about what the AI actually received
Ability to try a different extraction method
Result: The user sees "AI returned no items" and has no path forward.

Failure Mode 5: No Format Detection
Credit reports from Equifax, Experian, and TransUnion each have completely different formats:

Different section headers
Different field labels
Different date formats
Different account status terminology
Different inquiry sections
Different public records sections
The parser has been treating all three as identical. It is not.

Result: Even when text is clean, fields are misidentified because the wrong extraction logic is applied.

Failure Mode 6: Single-Pass Extraction
The parser makes one attempt to extract data and gives up. A production-grade parser should:

Try PDF extraction
Try paste normalization
Try format detection
Try AI with full context
Try AI with simplified prompt
Try regex fallback
Try section-by-section parsing
Prompt user for manual correction of specific fields
None of this retry/fallback logic exists.

// src/services/creditReportParser.ts
// The master orchestrator — calls all 7 stages in sequence

import { Stage1Extractor } from './parser/stage1Extractor';
import { Stage2Normalizer } from './parser/stage2Normalizer';
import { Stage3FormatDetector } from './parser/stage3FormatDetector';
import { Stage4Segmenter } from './parser/stage4Segmenter';
import { Stage5AIExtractor } from './parser/stage5AIExtractor';
import { Stage6Validator } from './parser/stage6Validator';

export interface ParserInput {
  type: 'pdf_file' | 'pasted_text' | 'base64_pdf';
  data: string | ArrayBuffer;
  fileName?: string;
}

export interface ParserProgress {
  stage: number;
  stageName: string;
  status: 'running' | 'complete' | 'failed' | 'fallback';
  message: string;
  itemsFound?: number;
}

export interface ParserResult {
  success: boolean;
  accounts: ParsedAccount[];
  personalInfo: ParsedPersonalInfo;
  inquiries: ParsedInquiry[];
  publicRecords: ParsedPublicRecord[];
  formatProfile: FormatProfile;
  confidence: number;            // 0-100 overall confidence
  warnings: ParserWarning[];
  rawTextPreview: string;        // First 2000 chars of normalized text
  stagesCompleted: number;
  fallbacksUsed: string[];
}

export type ParserWarning = {
  severity: 'info' | 'warn' | 'error';
  field?: string;
  accountId?: string;
  message: string;
};

export class CreditReportParser {

  private progress: (p: ParserProgress) => void;

  constructor(
    private aiRouter: AIRouter,
    onProgress?: (p: ParserProgress) => void
  ) {
    this.progress = onProgress ?? (() => {});
  }

  async parse(input: ParserInput): Promise<ParserResult> {

    const warnings: ParserWarning[] = [];
    const fallbacksUsed: string[] = [];

    // ── STAGE 1: RAW EXTRACTION ───────────────────────────
    this.progress({ stage: 1, stageName: 'Extracting Text', status: 'running',
      message: 'Reading document...' });

    const extractor = new Stage1Extractor();
    let rawText: string;

    try {
      rawText = await extractor.extract(input);
      this.progress({ stage: 1, stageName: 'Extracting Text', status: 'complete',
        message: `Extracted ${rawText.length.toLocaleString()} characters` });
    } catch (err) {
      this.progress({ stage: 1, stageName: 'Extracting Text', status: 'fallback',
        message: 'Primary extraction failed — trying fallback...' });
      rawText = await extractor.extractFallback(input);
      fallbacksUsed.push('Stage1:FallbackExtractor');

      if (!rawText || rawText.length < 100) {
        return this.buildFailureResult(
          'Could not extract text from this document. ' +
          'If this is a scanned PDF, please copy and paste the text manually. ' +
          'If you are pasting text, ensure you are copying from a PDF viewer (not a browser tab).',
          warnings, fallbacksUsed
        );
      }
    }

    // ── STAGE 2: NORMALIZATION ────────────────────────────
    this.progress({ stage: 2, stageName: 'Normalizing Text', status: 'running',
      message: 'Cleaning and normalizing extracted text...' });

    const normalizer = new Stage2Normalizer();
    const { normalized, normWarnings } = normalizer.normalize(rawText);
    warnings.push(...normWarnings);

    this.progress({ stage: 2, stageName: 'Normalizing Text', status: 'complete',
      message: `Normalized to ${normalized.length.toLocaleString()} characters` });

    // ── STAGE 3: FORMAT DETECTION ─────────────────────────
    this.progress({ stage: 3, stageName: 'Detecting Format', status: 'running',
      message: 'Identifying credit bureau and report format...' });

    const detector = new Stage3FormatDetector();
    const formatProfile = detector.detect(normalized);

    this.progress({ stage: 3, stageName: 'Detecting Format', status: 'complete',
      message: `Detected: ${formatProfile.bureauName} — ${formatProfile.reportType}` });

    if (formatProfile.confidence < 40) {
      warnings.push({
        severity: 'warn',
        message: `Low confidence in bureau detection (${formatProfile.confidence}%). ` +
          'Results may be less accurate. Please verify all parsed items.',
      });
    }

    // ── STAGE 4: SEGMENTATION ─────────────────────────────
    this.progress({ stage: 4, stageName: 'Segmenting Sections', status: 'running',
      message: 'Identifying accounts, inquiries, and public records...' });

    const segmenter = new Stage4Segmenter(formatProfile);
    const sections = segmenter.segment(normalized);

    this.progress({ stage: 4, stageName: 'Segmenting Sections', status: 'complete',
      message: `Found ${sections.accounts.length} account sections, ` +
        `${sections.inquiries?.length ?? 0} inquiry sections` });

    if (sections.accounts.length === 0) {
      warnings.push({
        severity: 'warn',
        message: 'No account sections detected in segmentation — AI will attempt full-document parse',
      });
      fallbacksUsed.push('Stage4:FullDocumentFallback');
    }

    // ── STAGE 5: AI EXTRACTION ────────────────────────────
    this.progress({ stage: 5, stageName: 'AI Extraction', status: 'running',
      message: 'AI is reading your accounts...' });

    const aiExtractor = new Stage5AIExtractor(this.aiRouter);
    let aiResult: Stage5Result;

    try {
      aiResult = await aiExtractor.extract(sections, formatProfile, normalized);
      this.progress({ stage: 5, stageName: 'AI Extraction', status: 'complete',
        message: `AI identified ${aiResult.accounts.length} accounts`,
        itemsFound: aiResult.accounts.length });
    } catch (err) {
      this.progress({ stage: 5, stageName: 'AI Extraction', status: 'fallback',
        message: 'AI extraction failed — running regex fallback parser...' });
      fallbacksUsed.push('Stage5:AIFailed:RegexFallback');
      warnings.push({ severity: 'warn',
        message: 'AI extraction failed. Regex fallback parser was used. ' +
          'Please carefully review all parsed items.' });
      aiResult = { accounts: [], inquiries: [], publicRecords: [],
        personalInfo: null as any };
    }

    // ── STAGE 6: REGEX AUGMENTATION & VALIDATION ─────────
    this.progress({ stage: 6, stageName: 'Validation & Augmentation', status: 'running',
      message: 'Validating and filling missing fields...' });

    const validator = new Stage6Validator(formatProfile);
    const { validated, augmented, validationWarnings } =
      await validator.validateAndAugment(aiResult, normalized);

    warnings.push(...validationWarnings);

    if (augmented.length > 0) {
      fallbacksUsed.push(`Stage6:RegexAugmented:${augmented.length}fields`);
    }

    this.progress({ stage: 6, stageName: 'Validation & Augmentation', status: 'complete',
      message: `Validated ${validated.accounts.length} accounts` });

    const overallConfidence = this.calculateOverallConfidence(
      validated, formatProfile, fallbacksUsed
    );

    return {
      success: validated.accounts.length > 0,
      accounts: validated.accounts,
      personalInfo: validated.personalInfo,
      inquiries: validated.inquiries,
      publicRecords: validated.publicRecords,
      formatProfile,
      confidence: overallConfidence,
      warnings,
      rawTextPreview: normalized.substring(0, 2000),
      stagesCompleted: 6,
      fallbacksUsed,
    };
  }

  private buildFailureResult(
    message: string,
    warnings: ParserWarning[],
    fallbacksUsed: string[]
  ): ParserResult {
    return {
      success: false,
      accounts: [],
      personalInfo: {} as any,
      inquiries: [],
      publicRecords: [],
      formatProfile: { bureauName: 'Unknown', reportType: 'unknown',
        confidence: 0, dateFormat: 'MM/DD/YYYY', sectionMarkers: {} },
      confidence: 0,
      warnings: [...warnings, { severity: 'error', message }],
      rawTextPreview: '',
      stagesCompleted: 0,
      fallbacksUsed,
    };
  }

  private calculateOverallConfidence(
    result: Stage6Result,
    format: FormatProfile,
    fallbacks: string[]
  ): number {
    let score = 100;
    if (fallbacks.some(f => f.includes('AIFailed'))) score -= 30;
    if (fallbacks.some(f => f.includes('FallbackExtractor'))) score -= 20;
    if (format.confidence < 60) score -= 15;
    if (result.accounts.some(a => !a.accountName)) score -= 10;
    if (result.accounts.some(a => !a.dateReported)) score -= 5;
    return Math.max(10, score);
  }
}

// src/services/parser/stage1Extractor.ts

import * as pdfjsLib from 'pdfjs-dist';
import type { TextItem, TextMarkedContent } from 'pdfjs-dist/types/src/display/api';

// Configure pdfjs worker
pdfjsLib.GlobalWorkerOptions.workerSrc =
  new URL('pdfjs-dist/build/pdf.worker.mjs', import.meta.url).href;

export class Stage1Extractor {

  async extract(input: ParserInput): Promise<string> {
    if (input.type === 'pasted_text') {
      return this.extractFromPaste(input.data as string);
    }
    if (input.type === 'pdf_file' || input.type === 'base64_pdf') {
      return this.extractFromPDF(input.data);
    }
    throw new Error(`Unknown input type: ${input.type}`);
  }

  // ── PDF EXTRACTION ──────────────────────────────────────

  async extractFromPDF(data: string | ArrayBuffer): Promise<string> {
    let pdfData: ArrayBuffer;

    if (typeof data === 'string') {
      // Base64 string from IPC
      const binary = atob(data.replace(/^data:[^;]+;base64,/, ''));
      pdfData = new Uint8Array(binary.length)
        .map((_, i) => binary.charCodeAt(i)).buffer;
    } else {
      pdfData = data;
    }

    const pdf = await pdfjsLib.getDocument({
      data: pdfData,
      useSystemFonts: true,
      disableFontFace: false,
      verbosity: 0,           // Suppress pdfjs console spam
    }).promise;

    const pageTexts: string[] = [];
    let totalTextItems = 0;

    for (let pageNum = 1; pageNum <= pdf.numPages; pageNum++) {
      const page = await pdf.getPage(pageNum);
      const pageText = await this.extractPageText(page, pageNum);
      pageTexts.push(pageText);
      totalTextItems += pageText.split('\n').length;
    }

    const fullText = pageTexts.join('\n\n=== PAGE BREAK ===\n\n');

    // Detect if this is a scanned PDF (no text layer)
    if (totalTextItems < 10) {
      throw new Error('SCANNED_PDF_NO_TEXT_LAYER');
    }

    return fullText;
  }

  private async extractPageText(
    page: pdfjsLib.PDFPageProxy,
    pageNum: number
  ): Promise<string> {

    const textContent = await page.getTextContent({
      includeMarkedContent: false,
      disableNormalization: false,
    });

    const viewport = page.getViewport({ scale: 1.0 });
    const pageWidth = viewport.width;

    // Group text items by their Y position (line grouping)
    const lineGroups = new Map<number, Array<{
      text: string;
      x: number;
      y: number;
      width: number;
      fontSize: number;
    }>>();

    for (const item of textContent.items) {
      const textItem = item as TextItem;
      if (!textItem.str?.trim()) continue;

      const transform = textItem.transform;
      const x = transform[4];
      const y = Math.round(transform[5]);  // Round Y to group nearby items
      const fontSize = Math.sqrt(transform[0] * transform[0] +
                                  transform[1] * transform[1]);

      const yKey = Math.round(y / 3) * 3;  // Bucket Y into 3pt groups

      if (!lineGroups.has(yKey)) {
        lineGroups.set(yKey, []);
      }
      lineGroups.get(yKey)!.push({
        text: textItem.str,
        x,
        y,
        width: textItem.width ?? 0,
        fontSize,
      });
    }

    // Sort lines from top to bottom (highest Y first in PDF coord system)
    const sortedYKeys = Array.from(lineGroups.keys()).sort((a, b) => b - a);

    // ── COLUMN DETECTION ──────────────────────────────────
    // Detect if this page has a two-column layout
    const midpoint = pageWidth / 2;
    let leftColumnCount = 0;
    let rightColumnCount = 0;

    for (const items of lineGroups.values()) {
      for (const item of items) {
        if (item.x < midpoint - 20) leftColumnCount++;
        else if (item.x > midpoint + 20) rightColumnCount++;
      }
    }

    const isTwoColumn = leftColumnCount > 10 && rightColumnCount > 10 &&
      Math.abs(leftColumnCount - rightColumnCount) < leftColumnCount * 0.6;

    // Build final text
    const lines: string[] = [];

    if (isTwoColumn) {
      // Two-column: read left column first (top to bottom), then right column
      const leftLines: string[] = [];
      const rightLines: string[] = [];

      for (const yKey of sortedYKeys) {
        const items = lineGroups.get(yKey)!;
        items.sort((a, b) => a.x - b.x);

        const leftItems = items.filter(i => i.x < midpoint);
        const rightItems = items.filter(i => i.x >= midpoint);

        if (leftItems.length) {
          leftLines.push(leftItems.map(i => i.text).join(' '));
        }
        if (rightItems.length) {
          rightLines.push(rightItems.map(i => i.text).join(' '));
        }
      }

      lines.push('=== LEFT COLUMN ===');
      lines.push(...leftLines);
      lines.push('=== RIGHT COLUMN ===');
      lines.push(...rightLines);

    } else {
      // Single column: read top to bottom, sort by X within each line
      for (const yKey of sortedYKeys) {
        const items = lineGroups.get(yKey)!;
        items.sort((a, b) => a.x - b.x);
        const lineText = items.map(i => i.text).join(' ');
        if (lineText.trim()) lines.push(lineText);
      }
    }

    return lines.join('\n');
  }

  // ── PASTE EXTRACTION ────────────────────────────────────

  extractFromPaste(text: string): string {
    if (!text || text.trim().length < 50) {
      throw new Error('PASTE_TOO_SHORT');
    }
    return text;
  }

  // ── FALLBACK EXTRACTION ─────────────────────────────────

  async extractFallback(input: ParserInput): Promise<string> {
    // Last resort: try alternative extraction strategies

    if (input.type === 'pdf_file' || input.type === 'base64_pdf') {

      try {
        // Strategy: Extract raw text strings without layout analysis
        const data = input.data;
        let pdfData: ArrayBuffer;

        if (typeof data === 'string') {
          const binary = atob(data.replace(/^data:[^;]+;base64,/, ''));
          pdfData = new Uint8Array(binary.length)
            .map((_, i) => binary.charCodeAt(i)).buffer;
        } else {
          pdfData = data as ArrayBuffer;
        }

        const pdf = await pdfjsLib.getDocument({ data: pdfData, verbosity: 0 }).promise;
        const allStrings: string[] = [];

        for (let i = 1; i <= pdf.numPages; i++) {
          const page = await pdf.getPage(i);
          const content = await page.getTextContent();
          for (const item of content.items) {
            const textItem = item as TextItem;
            if (textItem.str?.trim()) {
              allStrings.push(textItem.str.trim());
            }
          }
        }

        return allStrings.join(' ');

      } catch {
        return '';
      }
    }

    return input.data as string ?? '';
  }
}

// electron/main.cjs — add clipboard IPC handlers

const { clipboard } = require('electron');

// ── CLIPBOARD READ (Native Win32 fallback) ────────────────
ipcMain.handle('clipboard:readText', async () => {
  try {
    // Electron's clipboard reads Win32 clipboard directly
    const text = clipboard.readText('clipboard');
    return { success: true, text: text ?? '' };
  } catch (err) {
    return { success: false, text: '', error: err.message };
  }
});

ipcMain.handle('clipboard:readHTML', async () => {
  try {
    const html = clipboard.readHTML();
    // Strip HTML tags but preserve structure
    const text = html
      .replace(/<br\s*\/?>/gi, '\n')
      .replace(/<\/p>/gi, '\n\n')
      .replace(/<\/div>/gi, '\n')
      .replace(/<\/tr>/gi, '\n')
      .replace(/<\/td>/gi, '\t')
      .replace(/<[^>]+>/g, '')
      .replace(/&nbsp;/g, ' ')
      .replace(/&amp;/g, '&')
      .replace(/&lt;/g, '<')
      .replace(/&gt;/g, '>')
      .replace(/&#(\d+);/g, (_, n) => String.fromCharCode(n))
      .trim();
    return { success: true, text };
  } catch (err) {
    return { success: false, text: '', error: err.message };
  }
});

// electron/preload.cjs — add paste helpers

contextBridge.exposeInMainWorld('electronAPI', {
  // ... existing APIs ...

  // ── PASTE HELPERS ─────────────────────────────────────
  pasteText: async () => {
    // Strategy 1: Try navigator.clipboard (requires focus + permission)
    try {
      if (navigator.clipboard && navigator.clipboard.readText) {
        const text = await navigator.clipboard.readText();
        if (text && text.trim().length > 0) {
          return { success: true, text, source: 'navigator.clipboard' };
        }
      }
    } catch { /* fall through */ }

    // Strategy 2: Native Win32 clipboard via IPC
    try {
      const result = await ipcRenderer.invoke('clipboard:readText');
      if (result.success && result.text.trim().length > 0) {
        return { success: true, text: result.text, source: 'native_clipboard' };
      }
    } catch { /* fall through */ }

    // Strategy 3: HTML clipboard (for content from browser/PDF viewer)
    try {
      const result = await ipcRenderer.invoke('clipboard:readHTML');
      if (result.success && result.text.trim().length > 0) {
        return { success: true, text: result.text, source: 'html_clipboard' };
      }

export class PasteNormalizer {

  normalize(rawPaste: string): { text: string; source: PasteSource } {

    switch (source) {
      case 'adobe_acrobat':
        text = this.normalizeAdobePaste(text);
        break;
      case 'chrome_pdf':
        text = this.normalizeChromePDFPaste(text);
        break;
      case 'edge_pdf':
        text = this.normalizeEdgePDFPaste(text);
        break;
      case 'annual_credit_report':
        text = this.normalizeAnnualCreditReportPaste(text);
        break;
      case 'credit_karma':
        text = this.normalizeCreditKarmaPaste(text);
        break;
      case 'experian_web':
        text = this.normalizeExperianWebPaste(text);
        break;
      default:
        text = this.normalizeGenericPaste(text);
    }

    return { text, source };
  }

  private detectSource(text: string): PasteSource {
    if (text.includes('AnnualCreditReport') ||
        text.includes('annualcreditreport.com'))
      return 'annual_credit_report';

    if (text.includes('Credit Karma') || text.includes('creditkarma.com'))
      return 'credit_karma';

    if (text.includes('Experian') && text.includes('experian.com'))
      return 'experian_web';

    // Adobe pastes have em-dashes and special bullet chars
    if (/\u2014|\u2013|\u2022|\uf0b7/.test(text))
      return 'adobe_acrobat';

    // Edge PDF pastes have \r\n
    if (text.includes('\r\n'))
      return 'edge_pdf';

    return 'unknown';
  }

  private normalizeAdobePaste(text: string): string {
    return text
      // Em-dash → hyphen
      .replace(/[\u2013\u2014]/g, '-')
      // Bullet points → newline
      .replace(/[\u2022\u2023\u25e6\u2043\uf0b7]/g, '\n')
      // Smart quotes → straight quotes
      .replace(/[\u2018\u2019]/g, "'")
      .replace(/[\u201c\u201d]/g, '"')
      // Remove soft hyphens
      .replace(/\u00ad/g, '')
      // Normalize spaces
      .replace(/\u00a0/g, ' ')
      .replace(/\u2009/g, ' ')
      .replace(/\u202f/g, ' ');
  }

  private normalizeChromePDFPaste(text: string): string {
    // Chrome PDF viewer loses table structure — try to restore

      .replace(/\u00a0/g, ' ');
  }

  private normalizeEdgePDFPaste(text: string): string {
    return text
      .replace(/\r\n/g, '\n')
      .replace(/\r/g, '\n')
      .replace(/\u00a0/g, ' ');
  }

  private normalizeAnnualCreditReportPaste(text: string): string {

      .replace(/&nbsp;/g, ' ')
      .replace(/&amp;/g, '&')

  }

  private normalizeCreditKarmaPaste(text: string): string {

    return text
      .replace(/See details/gi, '')
      .replace(/Learn more/gi, '')
      .replace(/\(i\)/g, '')

  }

  private normalizeExperianWebPaste(text: string): string {
    return text
      .replace(/View account details/gi, '')
      .replace(/Dispute this item/gi, '')
      .replace(/\n{3,}/g, '\n\n');
  }

  private normalizeGenericPaste(text: string): string {
    return text
      .replace(/\r\n/g, '\n')
      .replace(/\r/g, '\n')
      .replace(/\u00a0/g, ' ')
      .replace(/\u00ad/g, '')
      .replace(/[\u2013\u2014]/g, '-')
      .replace(/[\u2018\u2019]/g, "'")
      .replace(/[\u201c\u201d]/g, '"');
  }

  private normalizeDate(dateStr: string | null): string | null {

        allAccounts.push(...chunkAccounts);

  private chunkText(text: string, maxChars: number): string[] {
    const chunks: string[] = [];
    let remaining = text;

    while (remaining.length > 0) {
      if (remaining.length <= maxChars) {
        chunks.push(remaining);
        break;
      }

      // Try to chunk at a natural boundary (double newline)
      let cutPoint = maxChars;
      const nearbyBreak = remaining.lastIndexOf('\n\n', maxChars);
      if (nearbyBreak > maxChars * 0.5) {
        cutPoint = nearbyBreak;
      }

      chunks.push(remaining.substring(0, cutPoint));
      remaining = remaining.substring(cutPoint);
    }

    return chunks;
  }

export class RegexFallbackParser {

  parseAccounts(text: string, format: FormatProfile): ParsedAccount[] {
    const accounts: ParsedAccount[] = [];

    // Strategy: Find account blocks using bureau-specific patterns
    const blocks = this.extractAccountBlocks(text, format);

    for (const block of blocks) {
      const account = this.parseAccountBlock(block, format);
      if (account) accounts.push(account);
    }

    return accounts;
  }

  private extractAccountBlocks(
    text: string,
    format: FormatProfile
  ): string[] {
    // Use bureau-specific section delimiters to split into account blocks
    const delimiters = BUREAU_SECTION_DELIMITERS[format.bureauName] ??
      BUREAU_SECTION_DELIMITERS.generic;

    const blocks: string[] = [];
    const lines = text.split('\n');
    let currentBlock: string[] = [];
    let inAccountSection = false;

    for (const line of lines) {
      const trimmed = line.trim();

      // Detect start of a new account
      if (this.isAccountHeader(trimmed, delimiters)) {
        if (currentBlock.length > 2) {
          blocks.push(currentBlock.join('\n'));
        }
        currentBlock = [line];
        inAccountSection = true;
        continue;
      }

      if (inAccountSection) {
        currentBlock.push(line);
      }
    }

    if (currentBlock.length > 2) {
      blocks.push(currentBlock.join('\n'));
    }

    return blocks;
  }

  private isAccountHeader(line: string, delimiters: BureauDelimiters): boolean {
    // Match known account header patterns per bureau
    return delimiters.accountHeaderPatterns.some(pattern => pattern.test(line));
  }

  private parseAccountBlock(
    block: string,
    format: FormatProfile
  ): ParsedAccount | null {

    const name = this.extractAccountName(block);
    if (!name) return null;  // Can't build an account without a name

    const account: ParsedAccount = {
      id: generateId(),
      accountName: name,
      accountNumber: this.extractAccountNumber(block),
      accountType: this.extractAccountType(block),
      balance: this.extractBalance(block),
      creditLimit: this.extractCreditLimit(block),
      pastDue: this.extractPastDue(block),
      paymentStatus: this.extractPaymentStatus(block),
      dateOpened: this.extractDate(block, DATE_PATTERNS.opened),
      dateClosed: this.extractDate(block, DATE_PATTERNS.closed),
      dateLastActive: this.extractDate(block, DATE_PATTERNS.lastActive),
      dateReported: this.extractDate(block, DATE_PATTERNS.reported),
      dateOfFirstDelinquency: this.extractDate(block, DATE_PATTERNS.dofd),
      paymentHistory: null,
      originalCreditor: this.extractOriginalCreditor(block),
      collectionAgency: null,
      isNegative: this.detectNegative(block),
      bureau: format.primaryBureau ?? 'unknown',
      rawText: block.substring(0, 200),
      confidence: 40,  // Regex confidence is lower than AI
    };

    return account;
  }

  private extractAccountName(block: string): string | null {
    // Patterns for account names in credit reports
    const patterns = [
      // "CAPITAL ONE" at start of line (uppercase creditor names)
      /^([A-Z][A-Z\s]{3,}(?:\s+[A-Z]+)*)/m,
      // "Account Name: Capital One"
      /(?:account\s+name|creditor|company)[:\s]+([^\n]+)/i,
      // Standard format: creditor name followed by account number
      /^(.{5,40})\s+\*{4}\d{4}/m,
    ];

    for (const pattern of patterns) {
      const match = block.match(pattern);
      if (match?.[1]) {
        const name = match[1].trim();
        // Filter out common false positives
        if (this.isValidCreditorName(name)) {
          return name;
        }
      }
    }

    return null;
  }

  private isValidCreditorName(name: string): boolean {
    const invalid = [
      'ACCOUNT INFORMATION', 'PAYMENT HISTORY', 'STATUS', 'BALANCE',
      'CREDIT LIMIT', 'DATE OPENED', 'LAST REPORTED', 'HIGH CREDIT',
    ];
    return name.length >= 3 &&
      name.length <= 60 &&
      !invalid.includes(name.toUpperCase()) &&
      !/^\d+$/.test(name);
  }

  private extractBalance(block: string): number | null {
    const patterns = [
      /(?:balance|amount|owed)[:\s]*\$?([\d,]+(?:\.\d{2})?)/i,
      /\$\s*([\d,]+(?:\.\d{2})?)/,
      /(?:^|\s)([\d,]{2,8}(?:\.\d{2})?)\s*(?:USD|dollars|\$)?(?:\s|$)/m,
    ];

    for (const pattern of patterns) {
      const match = block.match(pattern);
      if (match?.[1]) {
        const num = parseFloat(match[1].replace(/,/g, ''));
        if (!isNaN(num) && num >= 0 && num <= 9999999) return num;
      }
    }

    return null;
  }

  private extractDate(block: string, patterns: RegExp[]): string | null {
    for (const pattern of patterns) {
      const match = block.match(pattern);
      if (match?.[1]) {
        return this.normalizeDateString(match[1]);
      }
    }
    return null;
  }

  private normalizeDateString(dateStr: string): string | null {
    const mmddyyyy = dateStr.match(/(\d{1,2})\/(\d{1,2})\/(\d{4})/);
    if (mmddyyyy) {
      return `${mmddyyyy[3]}-${mmddyyyy[1].padStart(2,'0')}-${mmddyyyy[2].padStart(2,'0')}`;
    }

    const mmyyyy = dateStr.match(/(\d{1,2})\/(\d{4})/);
    if (mmyyyy) {
      return `${mmyyyy[2]}-${mmyyyy[1].padStart(2,'0')}-01`;
    }

    return null;
  }

  private detectNegative(block: string): boolean {
    const negativeTerms = /charge.?off|collection|derogatory|late|past due|
      delinquent|repossession|foreclosure|bankruptcy|unpaid|written.?off|
      settled|profit.?and.?loss|120\s+days|90\s+days|60\s+days/i;
    return negativeTerms.test(block);
  }

  private extractPaymentStatus(block: string): string | null {
    const patterns = [
      /(?:status|account status)[:\s]+([^\n]+)/i,
      /(?:payment status)[:\s]+([^\n]+)/i,
      /(charge.?off|collection|current|paid|closed|open|delinquent|late)/i,
    ];

    for (const pattern of patterns) {
      const match = block.match(pattern);
      if (match?.[1]) return match[1].trim().substring(0, 50);
    }

    return null;
  }

  private extractAccountNumber(block: string): string | null {
    const pattern = /\*{2,4}(\d{4})/;
    const match = block.match(pattern);
    return match ? `****${match[1]}` : null;
  }

  private extractAccountType(block: string): ParsedAccount['accountType'] {
    if (/revolv|credit card/i.test(block)) return 'revolving';
    if (/install|auto\s+loan|student|personal loan/i.test(block)) return 'installment';
    if (/mortgage|home\s+loan/i.test(block)) return 'mortgage';
    if (/collection/i.test(block)) return 'collection';

  private extractCreditLimit(block: string): number | null {
    const match = block.match(/(?:credit\s+limit|limit)[:\s]*\$?([\d,]+)/i);
    if (!match) return null;
    const num = parseFloat(match[1].replace(/,/g, ''));
    return isNaN(num) ? null : num;
  }

  private extractPastDue(block: string): number | null {
    const match = block.match(/(?:past\s+due|amount\s+past\s+due)[:\s]*\$?([\d,]+)/i);
    if (!match) return null;
    const num = parseFloat(match[1].replace(/,/g, ''));
    return isNaN(num) ? null : num;
  }

  private extractOriginalCreditor(block: string): string | null {
    const match = block.match(/(?:original\s+creditor|original\s+account)[:\s]+([^\n]+)/i);
    return match ? match[1].trim().substring(0, 60) : null;
  }

export interface FormatProfile {
  bureauName: 'Equifax' | 'Experian' | 'TransUnion' | 'Multi-Bureau' | 'Unknown';
  primaryBureau: 'equifax' | 'experian' | 'transunion' | 'unknown';
  reportType: 'full_report' | 'monitoring_export' | 'dispute_summary' | 'unknown';
  dateFormat: 'MM/DD/YYYY' | 'MM/YYYY' | 'YYYY-MM-DD' | 'MonthYYYY' | 'mixed';
  confidence: number;
  sectionMarkers: SectionMarkers;
  negativeStatusTerms: string[];
}

interface SectionMarkers {
  accountsHeader?: RegExp;
  inquiriesHeader?: RegExp;
  publicRecordsHeader?: RegExp;
  personalInfoHeader?: RegExp;
  accountSeparator?: RegExp;
}

export class Stage3FormatDetector {

  detect(text: string): FormatProfile {
    const sample = text.substring(0, 5000).toLowerCase();

    const equifaxScore = this.scoreEquifax(sample, text);
    const experianScore = this.scoreExperian(sample, text);
    const transunionScore = this.scoreTransUnion(sample, text);

    const maxScore = Math.max(equifaxScore, experianScore, transunionScore);
    const totalScore = equifaxScore + experianScore + transunionScore;

    let bureauName: FormatProfile['bureauName'] = 'Unknown';
    let primaryBureau: FormatProfile['primaryBureau'] = 'unknown';
    let confidence = 0;

    if (maxScore > 0) {
      if (equifaxScore === maxScore && equifaxScore > experianScore &&
          equifaxScore > transunionScore) {
        bureauName = 'Equifax';
        primaryBureau = 'equifax';
        confidence = Math.round((equifaxScore / totalScore) * 100);
      } else if (experianScore === maxScore && experianScore > equifaxScore &&
                 experianScore > transunionScore) {
        bureauName = 'Experian';
        primaryBureau = 'experian';
        confidence = Math.round((experianScore / totalScore) * 100);
      } else if (transunionScore === maxScore) {
        bureauName = 'TransUnion';
        primaryBureau = 'transunion';
        confidence = Math.round((transunionScore / totalScore) * 100);
      }

      // If all three scores are significant, it's a 3-bureau report
      if (equifaxScore > 15 && experianScore > 15 && transunionScore > 15) {
        bureauName = 'Multi-Bureau';
        primaryBureau = 'equifax';  // Default to Equifax order in 3-bureau reports
        confidence = 85;
      }
    }

    const dateFormat = this.detectDateFormat(text);
    const reportType = this.detectReportType(sample);
    const sectionMarkers = this.getSectionMarkers(bureauName);
    const negativeStatusTerms = this.getNegativeStatusTerms(bureauName);

    return {
      bureauName,
      primaryBureau,
      reportType,
      dateFormat,
      confidence,
      sectionMarkers,
      negativeStatusTerms,
    };
  }

  private scoreEquifax(sample: string, fullText: string): number {
    let score = 0;
    if (sample.includes('equifax')) score += 30;
    if (sample.includes('equifax information services')) score += 20;
    if (fullText.includes('Date Verified:')) score += 10;
    if (fullText.includes('Scheduled to continue on record')) score += 10;
    if (fullText.match(/Account History\s+\d{2}\/\d{2}\/\d{4}/)) score += 10;
    if (fullText.includes('High Credit')) score += 8;
    if (fullText.includes('Credit Items')) score += 8;
    if (fullText.includes('Negative Items')) score += 8;
    return score;
  }

  private scoreExperian(sample: string, fullText: string): number {
    let score = 0;
    if (sample.includes('experian')) score += 30;
    if (sample.includes('experian information solutions')) score += 20;
    if (fullText.includes('Status Details:')) score += 10;
    if (fullText.includes('Balance History')) score += 10;
    if (fullText.includes('Payment History Legend')) score += 10;
    if (fullText.match(/Months Reviewed:\s+\d+/i)) score += 8;
    if (fullText.includes('Potentially Negative')) score += 8;
    if (fullText.match(/Your statement\s*:/i)) score += 8;
    return score;
  }

  private scoreTransUnion(sample: string, fullText: string): number {
    let score = 0;
    if (sample.includes('transunion')) score += 30;
    if (sample.includes('trans union')) score += 25;
    if (fullText.includes('Date of First Delinquency:')) score += 10;
    if (fullText.includes('Dispute Status:')) score += 10;
    if (fullText.includes('Consumer Statement:')) score += 8;
    if (fullText.match(/Remarks:\s+/)) score += 8;
    if (fullText.includes('Date Account Information Provided to TransUnion')) score += 10;
    return score;
  }

  private detectDateFormat(text: string): FormatProfile['dateFormat'] {
    const sample = text.substring(0, 10000);

    const mmddyyyy = (sample.match(/\d{2}\/\d{2}\/\d{4}/g) ?? []).length;
    const mmyyyy = (sample.match(/\d{2}\/\d{4}/g) ?? []).length;
    const isoFormat = (sample.match(/\d{4}-\d{2}-\d{2}/g) ?? []).length;
    const monthYear = (sample.match(
      /(?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec)\w*\s+\d{4}/gi
    ) ?? []).length;

    const max = Math.max(mmddyyyy, mmyyyy, isoFormat, monthYear);
    if (max === 0) return 'MM/DD/YYYY';  // Default assumption
    if (mmddyyyy === max) return 'MM/DD/YYYY';
    if (mmyyyy === max) return 'MM/YYYY';
    if (isoFormat === max) return 'YYYY-MM-DD';
    return 'MonthYYYY';
  }

  private detectReportType(sample: string): FormatProfile['reportType'] {
    if (sample.includes('annual credit report') ||
        sample.includes('full credit report'))
      return 'full_report';
    if (sample.includes('credit monitoring') ||
        sample.includes('credit score alert'))
      return 'monitoring_export';
    if (sample.includes('dispute') && sample.includes('investigation'))
      return 'dispute_summary';
    return 'full_report';
  }

  private getSectionMarkers(bureau: string): SectionMarkers {
    const markers: Record<string, SectionMarkers> = {
      Equifax: {
        accountsHeader: /(?:Credit\s+Items|Account\s+Information|Open\s+Accounts)/i,
        inquiriesHeader: /(?:Inquiries|Requests\s+for\s+Your\s+Credit\s+History)/i,
        publicRecordsHeader: /(?:Public\s+Record|Bankruptcy|Court)/i,
        personalInfoHeader: /(?:Personal\s+Information|Consumer\s+Information)/i,
        accountSeparator: /^={3,}|^-{3,}/m,
      },
      Experian: {
        accountsHeader: /(?:Accounts|Potentially\s+Negative\s+Accounts|Accounts\s+in\s+Good)/i,
        inquiriesHeader: /(?:Inquiries|Hard\s+Inquiries|Credit\s+Inquiries)/i,
        publicRecordsHeader: /(?:Public\s+Records)/i,
        personalInfoHeader: /(?:Personal\s+Information|Profile)/i,
        accountSeparator: /^-{3,}/m,
      },
      TransUnion: {
        accountsHeader: /(?:Account\s+Review|Open\s+Accounts|Closed\s+Accounts)/i,
        inquiriesHeader: /(?:Inquiries|Regular\s+Inquiries)/i,
        publicRecordsHeader: /(?:Public\s+Records|Legal\s+Items)/i,
        personalInfoHeader: /(?:Personal\s+Information|Identifying\s+Information)/i,
        accountSeparator: /^[A-Z][A-Z\s]{5,}$/m,
      },
    };

    return markers[bureau] ?? markers.Equifax;
  }

  private getNegativeStatusTerms(bureau: string): string[] {
    const common = [
      'charge off', 'charge-off', 'charged off',
      'collection', 'collections',
      'late', 'delinquent', 'derogatory',
      '30 days late', '60 days late', '90 days late', '120 days late',
      'repossession', 'foreclosure', 'bankruptcy',
      'settled', 'debt settlement',
    ];

    const bureauSpecific: Record<string, string[]> = {
      Equifax: [...common, 'profit and loss writeoff', 'bad debt'],
      Experian: [...common, 'potentially negative', 'past due'],
      TransUnion: [...common, 'seriously past due', 'account charged off'],
    };

    return bureauSpecific[bureau] ?? common;
  }
}

            if (result.success && result.text) {
              setPasteText(result.text);
            }

// src/services/vaultEncryptionService.ts — v4.1 upgrade

export class VaultEncryptionService {

  private masterKey: CryptoKey | null = null;
  private masterKeyHex: string | null = null;

  async initialize(): Promise<void> {
    const keyHex = await window.electronAPI.getVaultMasterKey();
    if (!keyHex) throw new Error('Vault master key unavailable');

    this.masterKeyHex = keyHex;
    const keyBytes = hexToBytes(keyHex);

    const rawKey = await crypto.subtle.importKey(
      'raw', keyBytes,
      { name: 'AES-GCM' },
      false,
      ['encrypt', 'decrypt']
    );

    this.masterKey = rawKey;
  }

  // ── ENCRYPT ────────────────────────────────────────────────
  async encryptBlob(data: ArrayBuffer): Promise<ArrayBuffer> {
    if (!this.masterKey) await this.initialize();

    const iv = crypto.getRandomValues(new Uint8Array(12));
    const encrypted = await crypto.subtle.encrypt(
      { name: 'AES-GCM', iv, tagLength: 128 },
      this.masterKey!,
      data
    );

    // Layout: [IV (12 bytes) | ciphertext+tag]
    const result = new Uint8Array(12 + encrypted.byteLength);
    result.set(iv, 0);
    result.set(new Uint8Array(encrypted), 12);
    return result.buffer;
  }

  // ── DECRYPT ────────────────────────────────────────────────
  async decryptBlob(data: ArrayBuffer): Promise<ArrayBuffer> {
    if (!this.masterKey) await this.initialize();

    if (data.byteLength < 13) {
      throw new Error('Encrypted data too short — may be corrupted');
    }

    const iv = new Uint8Array(data, 0, 12);
    const ciphertext = new Uint8Array(data, 12);

    try {
      return await crypto.subtle.decrypt(
        { name: 'AES-GCM', iv, tagLength: 128 },
        this.masterKey!,
        ciphertext
      );
    } catch {
      throw new Error(
        'Decryption failed — file may be corrupted or master key changed. ' +
        'Try restoring from a backup.'
      );
    }
  }

  // ── ENCRYPT STRING ─────────────────────────────────────────
  async encryptString(text: string): Promise<ArrayBuffer> {
    const bytes = new TextEncoder().encode(text);
    return this.encryptBlob(bytes.buffer);
  }

  // ── DECRYPT STRING ─────────────────────────────────────────
  async decryptString(data: ArrayBuffer): Promise<string> {
    const decrypted = await this.decryptBlob(data);
    return new TextDecoder().decode(decrypted);
  }

  // ── SHA-256 ────────────────────────────────────────────────
  async sha256(data: ArrayBuffer): Promise<string> {
    const hash = await crypto.subtle.digest('SHA-256', data);
    return Array.from(new Uint8Array(hash))
      .map(b => b.toString(16).padStart(2, '0'))
      .join('');
  }
}

function hexToBytes(hex: string): Uint8Array {
  if (hex.length % 2 !== 0) throw new Error('Invalid hex string');
  const bytes = new Uint8Array(hex.length / 2);
  for (let i = 0; i < hex.length; i += 2) {
    bytes[i / 2] = parseInt(hex.substring(i, i + 2), 16);
  }
  return bytes;
}

## 14. CREDIT REPORT PARSER — WORLD-CLASS UPGRADE

This is the most critical fix in the entire document. The parser has been unreliable because it relies on a single AI call against raw, unnormalized text. The new architecture uses a **five-layer parsing pipeline** that handles every realistic credit report format.

### Why the Current Parser Fails

```
Current flow (broken):
PDF text (raw, messy) → single AI prompt → hope for structured output

Problems:
1. Raw PDF text has ligatures, garbled columns, broken line wraps
2. Single AI call has no fallback if AI misreads format
3. No pre-normalization — AI wastes context window on whitespace/junk
4. No post-validation — bad output silently accepted
5. No regex safety net when AI returns empty
6. Paste path bypasses PDF normalization entirely
7. Token limits hit on large reports — truncation = missing accounts
```

### The New Five-Layer Parsing Pipeline

```
Layer 1: RAW TEXT ACQUISITION
  ├── PDF upload path → pdfjs-dist multi-page extract → raw pages array
  ├── Paste path → clipboard normalization → same raw pages array
  └── File path path → read-file-as-base64 → decode → same entry point

Layer 2: TEXT NORMALIZATION
  ├── NFKC Unicode normalization
  ├── Ligature repair (ﬁ→fi, ﬂ→fl, etc.)
  ├── Hyphenation fix (broken words across line breaks)
  ├── Column detection and reflow
  ├── Control character strip
  ├── Whitespace normalization
  └── Section boundary detection

Layer 3: STRUCTURAL HEURISTIC PRE-PARSE
  ├── Regex-based account block detection
  ├── Date extraction (opened, closed, last active, DOFD)
  ├── Balance extraction
  ├── Account number masking detection
  ├── Status field extraction (Open/Closed/Derogatory/Collection)
  └── Bureau field detection (EQ/TU/EX specific formats)

Layer 4: AI SEMANTIC ENHANCEMENT
  ├── Chunked processing (max 4000 tokens per chunk)
  ├── Structured JSON output with schema validation
  ├── Per-chunk retry with provider failover
  ├── Merge and deduplication across chunks
  └── Confidence scoring per field

Layer 5: POST-VALIDATION AND ENRICHMENT
  ├── Schema validation (required fields present)
  ├── Date sanity checks (DOFD before close date, etc.)
  ├── Account type classification
  ├── Deletability pre-score
  └── User review flag on low-confidence items
```

### Layer 1: Multi-Path Text Acquisition

```typescript
// src/services/creditReportParser/textAcquisition.ts

import * as pdfjs from 'pdfjs-dist';
import type { TextItem } from 'pdfjs-dist/types/src/display/api';

// Configure pdfjs worker — must be set before any call
pdfjs.GlobalWorkerOptions.workerSrc =
  new URL('pdfjs-dist/build/pdf.worker.mjs', import.meta.url).href;

export interface AcquiredText {
  source: 'pdf' | 'paste' | 'file';
  rawPages: string[];       // One string per page
  fullText: string;         // Joined with form feeds
  pageCount: number;
  warnings: string[];
}

// ── PDF ACQUISITION ───────────────────────────────────────────────────

export async function acquireFromPDFBuffer(
  buffer: ArrayBuffer
): Promise<AcquiredText> {
  const warnings: string[] = [];

  let pdf: pdfjs.PDFDocumentProxy;
  try {
    pdf = await pdfjs.getDocument({
      data: new Uint8Array(buffer),
      useWorkerFetch: false,
      isEvalSupported: false,
      useSystemFonts: true,
      // Increase limits for large reports
      rangeChunkSize: 65536,
    }).promise;
  } catch (err) {
    throw new Error(
      'PDF could not be opened. Make sure it is a valid PDF file. ' +
      'Error: ' + (err as Error).message
    );
  }

  const rawPages: string[] = [];

  for (let pageNum = 1; pageNum <= pdf.numPages; pageNum++) {
    try {
      const page = await pdf.getPage(pageNum);
      const textContent = await page.getTextContent({
        includeMarkedContent: false,
        disableNormalization: false,
      });

      // ── COLUMN-AWARE TEXT EXTRACTION ─────────────────────────
      // Sort text items by Y position (top to bottom), then X (left to right)
      // This is critical for credit reports which use multi-column layouts
      const items = textContent.items as TextItem[];

      // Group items by approximate Y coordinate (within 3px = same line)
      const lineMap = new Map<number, TextItem[]>();
      for (const item of items) {
        const y = Math.round(item.transform[5] / 3) * 3; // Round to 3px grid
        if (!lineMap.has(y)) lineMap.set(y, []);
        lineMap.get(y)!.push(item);
      }

      // Sort lines top-to-bottom (higher Y = higher on page in PDF coords)
      const sortedYs = Array.from(lineMap.keys()).sort((a, b) => b - a);

      const pageLines: string[] = [];
      for (const y of sortedYs) {
        const lineItems = lineMap.get(y)!.sort((a, b) =>
          a.transform[4] - b.transform[4] // Sort left to right by X
        );
        const lineText = lineItems.map(i => i.str).join(' ').trim();
        if (lineText) pageLines.push(lineText);
      }

      rawPages.push(pageLines.join('\n'));

    } catch (pageErr) {
      warnings.push(`Page ${pageNum} extraction failed: ${(pageErr as Error).message}`);
      rawPages.push(''); // Keep page slot
    }
  }

  return {
    source: 'pdf',
    rawPages,
    fullText: rawPages.join('\f'), // Form feed = page separator
    pageCount: pdf.numPages,
    warnings,
  };
}

// ── PASTE ACQUISITION ─────────────────────────────────────────────────

export async function acquireFromPaste(rawPaste: string): Promise<AcquiredText> {
  if (!rawPaste || rawPaste.trim().length === 0) {
    throw new Error('Pasted text is empty. Please paste your credit report text.');
  }

  // Split by form feeds or double newlines to simulate pages
  const pages = rawPaste
    .split(/\f|\r?\n{3,}/)
    .filter(p => p.trim().length > 0);

  return {
    source: 'paste',
    rawPages: pages.length > 0 ? pages : [rawPaste],
    fullText: rawPaste,
    pageCount: pages.length,
    warnings: [],
  };
}

// ── FILE PATH ACQUISITION (via Electron IPC) ──────────────────────────

export async function acquireFromFilePath(
  filePath: string
): Promise<AcquiredText> {
  // Read via Electron IPC (main process reads file, returns base64)
  const base64: string = await window.electronAPI.readFileAsBase64(filePath);

  if (!base64 || base64.length === 0) {
    throw new Error('File could not be read or is empty: ' + filePath);
  }

  // Detect if this is a PDF (check magic bytes after decode)
  const bytes = Uint8Array.from(atob(base64.substring(0, 100)), c => c.charCodeAt(0));
  const isPDF =
    bytes[0] === 0x25 && // %
    bytes[1] === 0x50 && // P
    bytes[2] === 0x44 && // D
    bytes[3] === 0x46;   // F

  if (isPDF) {
    const binary = atob(base64);
    const buffer = new ArrayBuffer(binary.length);
    const view = new Uint8Array(buffer);
    for (let i = 0; i < binary.length; i++) view[i] = binary.charCodeAt(i);
    return acquireFromPDFBuffer(buffer);
  }

  // Plain text file
  const text = atob(base64);
  return acquireFromPaste(text);
}
```

```typescript
// src/services/creditReportParser/textNormalizer.ts

export interface NormalizedText {
  pages: string[];
  fullText: string;
  sections: ReportSection[];
  normalizationLog: string[];
}

export interface ReportSection {
  type: SectionType;
  rawText: string;
  startPage: number;
  confidence: number;
}

export type SectionType =
  | 'personal_info'
  | 'account_history'
  | 'negative_items'
  | 'collections'
  | 'inquiries'
  | 'public_records'
  | 'score_summary'
  | 'unknown';

// ── UNICODE AND CHARACTER NORMALIZATION ───────────────────────────────

const LIGATURE_MAP: Record<string, string> = {
  '\uFB00': 'ff',
  '\uFB01': 'fi',
  '\uFB02': 'fl',
  '\uFB03': 'ffi',
  '\uFB04': 'ffl',
  '\uFB05': 'st',
  '\uFB06': 'st',
  '\u2019': "'",
  '\u2018': "'",
  '\u201C': '"',
  '\u201D': '"',
  '\u2013': '-',
  '\u2014': '-',
  '\u2022': '*',
  '\u00B7': '*',
  '\u2012': '-',
  '\u00AD': '-', // Soft hyphen
};

export function normalizeText(acquired: AcquiredText): NormalizedText {
  const log: string[] = [];

  const normalizedPages = acquired.rawPages.map((page, idx) => {
    let text = page;

    // Step 1: NFKC Unicode normalization (decomposes compatibility chars)
    text = text.normalize('NFKC');

    // Step 2: Replace known ligatures
    for (const [lig, rep] of Object.entries(LIGATURE_MAP)) {
      text = text.replaceAll(lig, rep);
    }

    // Step 3: Strip control characters (keep \n, \t, \r)
    text = text.replace(/[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]/g, '');

    // Step 4: Fix common PDF hyphenation breaks
    // "pay-\nment" → "payment"
    text = text.replace(/(\w)-\n(\w)/g, '$1$2');

    // Step 5: Normalize line endings
    text = text.replace(/\r\n/g, '\n').replace(/\r/g, '\n');

    // Step 6: Collapse excessive whitespace within lines
    // but PRESERVE newlines (they are structural)
    text = text.split('\n')
      .map(line => line.replace(/[ \t]+/g, ' ').trim())
      .join('\n');

    // Step 7: Remove repetitive separator lines
    // e.g., "--------" or "========" or "........"
    text = text.replace(/^[-=_.]{4,}\s*$/gm, '');

    // Step 8: Collapse 3+ blank lines into 2
    text = text.replace(/\n{3,}/g, '\n\n');

    log.push(`Page ${idx + 1}: normalized (${page.length} → ${text.length} chars)`);

    return text;
  });

  const fullText = normalizedPages.join('\n\n---PAGE BREAK---\n\n');

  // Detect sections
  const sections = detectSections(normalizedPages);
  log.push(`Detected ${sections.length} sections`);

  return {
    pages: normalizedPages,
    fullText,
    sections,
    normalizationLog: log,
  };
}

// ── SECTION DETECTION ─────────────────────────────────────────────────

const SECTION_PATTERNS: Array<{ type: SectionType; patterns: RegExp[] }> = [
  {
    type: 'personal_info',
    patterns: [
      /personal\s+information/i,
      /consumer\s+information/i,
      /your\s+information/i,
      /name\s*:\s*[A-Z]/i,
    ],
  },
  {
    type: 'account_history',
    patterns: [
      /account\s+history/i,
      /account\s+information/i,
      /tradelines/i,
      /your\s+accounts/i,
      /open\s+accounts/i,
    ],
  },
  {
    type: 'negative_items',
    patterns: [
      /negative\s+items/i,
      /adverse\s+accounts/i,
      /derogatory\s+information/i,
      /potentially\s+negative/i,
    ],
  },
  {
    type: 'collections',
    patterns: [
      /collection\s+accounts?/i,
      /collections/i,
      /third[\s-]party\s+collection/i,
    ],
  },
  {
    type: 'inquiries',
    patterns: [
      /inquiries/i,
      /credit\s+inquiries/i,
      /requests\s+for\s+credit/i,
      /who\s+has\s+requested/i,
    ],
  },
  {
    type: 'public_records',
    patterns: [
      /public\s+records?/i,
      /bankruptc/i,
      /judgment/i,
      /tax\s+lien/i,
    ],
  },
  {
    type: 'score_summary',
    patterns: [
      /credit\s+score/i,
      /fico/i,
      /vantage\s*score/i,
      /score\s+summary/i,
    ],
  },
];

function detectSections(pages: string[]): ReportSection[] {
  const sections: ReportSection[] = [];

  pages.forEach((page, pageIdx) => {
    const lines = page.split('\n');

    for (let i = 0; i < lines.length; i++) {
      for (const { type, patterns } of SECTION_PATTERNS) {
        for (const pattern of patterns) {
          if (pattern.test(lines[i])) {
            // Grab up to 100 lines from this point as the section body
            const rawText = lines.slice(i, Math.min(i + 100, lines.length)).join('\n');
            sections.push({
              type,
              rawText,
              startPage: pageIdx,
              confidence: 0.8,
            });
            break;
          }
        }
      }
    }
  });

  return sections;
}
```

### Layer 3: Structural Heuristic Pre-Parser

```typescript
// src/services/creditReportParser/heuristicParser.ts
// Runs BEFORE AI — extracts what it can via regex
// This is the safety net that ensures we ALWAYS get something

export interface HeuristicParseResult {
  accounts: HeuristicAccount[];
  inquiries: HeuristicInquiry[];
  personalInfo: Partial<HeuristicPersonalInfo>;
  parseConfidence: number;
  rawMatchCount: number;
}

export interface HeuristicAccount {
  accountName: string;
  accountNumber?: string;
  balance?: number;
  dateOpened?: string;
  dateClosed?: string;
  dateReported?: string;
  dateOfFirstDelinquency?: string;
  status?: string;
  type?: string;
  bureaus: string[];
  rawBlock: string;
  confidence: number;
}

export interface HeuristicInquiry {
  inquiringCompany: string;
  dateOfInquiry: string;
  bureau: string;
  rawLine: string;
}

export interface HeuristicPersonalInfo {
  fullName: string;
  address: string;
  ssn: string;
  dob: string;
  employer: string;
}

// ── REGEX PATTERNS ────────────────────────────────────────────────────

const PATTERNS = {
  // Account block openers — lines that typically start an account entry
  accountBlockStart: /^([A-Z][A-Z0-9\s&',.\-/]{2,50})\s*$/m,

  // Account number patterns (masked and full)
  accountNumber: /(?:account\s*#?|acct\.?\s*#?|account\s+number)[:\s]+([*\dX]{4,20})/i,
  accountNumberAlt: /\b([*X]{4,8}\d{4})\b/, // e.g., ****1234

  // Balance patterns
  balance: /(?:balance|amount|high\s+credit|credit\s+limit)[:\s]+\$?([\d,]+(?:\.\d{2})?)/i,
  balanceAlt: /\$([\d,]+(?:\.\d{2})?)/,

  // Date patterns (various formats seen in credit reports)
  dateOpened: /(?:date\s+opened|opened|open\s+date)[:\s]+(\d{1,2}[\/\-]\d{4}|\w+\s+\d{4})/i,
  dateClosed: /(?:date\s+closed|closed|close\s+date)[:\s]+(\d{1,2}[\/\-]\d{4}|\w+\s+\d{4})/i,
  dateReported: /(?:date\s+reported|reported|last\s+reported)[:\s]+(\d{1,2}[\/\-]\d{4}|\w+\s+\d{4})/i,
  dateDOFD: /(?:date\s+of\s+first\s+delinquency|first\s+delinquency|dofd)[:\s]+(\d{1,2}[\/\-]\d{4}|\w+\s+\d{4})/i,
  dateLastActive: /(?:last\s+active|last\s+payment|date\s+of\s+last\s+activity)[:\s]+(\d{1,2}[\/\-]\d{4}|\w+\s+\d{4})/i,

  // Status patterns
  status: /(?:status|account\s+status|pay\s+status)[:\s]+(open|closed|charge[\s\-]off|collection|derogatory|delinquent|current|ok|paid|30|60|90|120|150|180)/i,

  // Account type
  accountType: /(?:account\s+type|type)[:\s]+(revolving|installment|mortgage|auto|student|collection|charge[\s-]card|credit\s+card|line\s+of\s+credit)/i,

  // Bureau indicators
  equifax: /\b(equifax|EQ|EFX)\b/i,
  experian: /\b(experian|EX|EXP)\b/i,
  transunion: /\b(transunion|trans\s+union|TU|TRU)\b/i,

  // Inquiry pattern
  inquiry: /^([A-Z][A-Z0-9\s&',.\-/]{2,50})\s+(\d{1,2}[\/\-]\d{1,2}[\/\-]\d{2,4})\s*(equifax|experian|transunion|EQ|EX|TU)?/im,

  // Creditor name exclusions (lines that are NOT account names)
  notAnAccount: /^(page\s+\d|continued|account\s+history|section|your\s+information|credit\s+score|inquir|public\s+record)/i,

  // DOFD 7-year calculation helper
  dollarAmount: /\$[\d,]+/,
};

// ── KNOWN CREDITOR NAME NORMALIZER ────────────────────────────────────

const CREDITOR_ALIASES: Record<string, string> = {
  'CAPITAL ONE BANK': 'Capital One',
  'CAP ONE': 'Capital One',
  'CAPONE': 'Capital One',
  'CHASE BANK': 'Chase',
  'JPMORGAN CHASE': 'Chase',
  'CITIBANK': 'Citi',
  'CITI BANK': 'Citi',
  'BANK OF AMERICA': 'Bank of America',
  'BOA': 'Bank of America',
  'DISCOVER BANK': 'Discover',
  'DISCOVER FIN': 'Discover',
  'WELLS FARGO BANK': 'Wells Fargo',
  'AMERICAN EXPRESS': 'American Express',
  'AMEX': 'American Express',
  'SYNCHRONY BANK': 'Synchrony',
  'SYNCH': 'Synchrony',
  'MIDLAND CREDIT': 'Midland Credit Management',
  'MIDLAND FUNDING': 'Midland Credit Management',

  'NAVIENT': 'Navient',
  'SALLIE MAE': 'Sallie Mae',

function normalizeCreditorName(raw: string): string {
  const upper = raw.trim().toUpperCase();
  for (const [alias, normalized] of Object.entries(CREDITOR_ALIASES)) {
    if (upper.includes(alias)) return normalized;
  }
  // Title case the raw name
  return raw.trim()
    .toLowerCase()
    .replace(/\b\w/g, c => c.toUpperCase());
}

// ── MAIN HEURISTIC PARSER ─────────────────────────────────────────────

export function heuristicParse(normalized: NormalizedText): HeuristicParseResult {
  const accounts: HeuristicAccount[] = [];
  const inquiries: HeuristicInquiry[] = [];
  const personalInfo: Partial<HeuristicPersonalInfo> = {};

  const fullText = normalized.fullText;
  const lines = fullText.split('\n');

  // ── EXTRACT ACCOUNT BLOCKS ────────────────────────────────────────
  // Strategy: look for lines that match known account block start patterns
  // then collect all lines until the next block start

  const blockStartIndices: number[] = [];

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i].trim();
    if (!line || line.length < 3) continue;

    // Skip obvious non-account lines
    if (PATTERNS.notAnAccount.test(line)) continue;
    if (PATTERNS.dollarAmount.test(line) && line.length < 10) continue;

    // A block start: ALL CAPS line of 3-50 chars, possibly followed by
    // account detail lines (containing balance, date, status)
    const isBlockStart =
      /^[A-Z][A-Z0-9\s&',.\-/]{2,49}$/.test(line) &&
      !line.match(/^\d/) &&
      line.length >= 3 &&
      line.length <= 60;

    if (isBlockStart) {
      // Peek ahead — if next non-empty lines contain account keywords,
      // this is an account block
      const nextLines = lines.slice(i + 1, i + 8).join(' ').toLowerCase();
      const hasAccountContent =
        /balance|opened|status|account|reported|payment|limit|delinquent|collection|charge/.test(nextLines);

      if (hasAccountContent) {
        blockStartIndices.push(i);
      }
    }
  }

  // Extract each block's text
  for (let b = 0; b < blockStartIndices.length; b++) {
    const startIdx = blockStartIndices[b];
    const endIdx = b + 1 < blockStartIndices.length
      ? blockStartIndices[b + 1]
      : Math.min(startIdx + 40, lines.length);

    const blockLines = lines.slice(startIdx, endIdx);
    const blockText = blockLines.join('\n');
    const accountName = normalizeCreditorName(lines[startIdx]);

    const account: HeuristicAccount = {
      accountName,
      bureaus: [],
      rawBlock: blockText,
      confidence: 0.5,
    };

    // Extract fields from block text
    const acctNumMatch = blockText.match(PATTERNS.accountNumber) ||
                         blockText.match(PATTERNS.accountNumberAlt);
    if (acctNumMatch) account.accountNumber = acctNumMatch[1];

    const balMatch = blockText.match(PATTERNS.balance) ||
                     blockText.match(PATTERNS.balanceAlt);
    if (balMatch) {
      account.balance = parseFloat(balMatch[1].replace(/,/g, ''));
    }

    const openMatch = blockText.match(PATTERNS.dateOpened);
    if (openMatch) account.dateOpened = openMatch[1];

    const closeMatch = blockText.match(PATTERNS.dateClosed);
    if (closeMatch) account.dateClosed = closeMatch[1];

    const repMatch = blockText.match(PATTERNS.dateReported);
    if (repMatch) account.dateReported = repMatch[1];

    const dofdMatch = blockText.match(PATTERNS.dateDOFD);
    if (dofdMatch) account.dateOfFirstDelinquency = dofdMatch[1];

    const statusMatch = blockText.match(PATTERNS.status);
    if (statusMatch) account.status = statusMatch[1];

    const typeMatch = blockText.match(PATTERNS.accountType);
    if (typeMatch) account.type = typeMatch[1];

    // Bureau detection
    if (PATTERNS.equifax.test(blockText)) account.bureaus.push('equifax');
    if (PATTERNS.experian.test(blockText)) account.bureaus.push('experian');
    if (PATTERNS.transunion.test(blockText)) account.bureaus.push('transunion');
    if (account.bureaus.length === 0) account.bureaus.push('equifax'); // Default

    // Boost confidence if we found multiple fields
    const fieldCount = [
      account.accountNumber,
      account.balance,
      account.dateOpened,
      account.status,
    ].filter(Boolean).length;
    account.confidence = 0.3 + (fieldCount * 0.15);

    accounts.push(account);
  }

  // ── EXTRACT INQUIRIES ─────────────────────────────────────────────
  const inquirySection = normalized.sections.find(s => s.type === 'inquiries');
  const inquiryText = inquirySection
    ? inquirySection.rawText
    : normalized.fullText;

  const inquiryLines = inquiryText.split('\n');
  for (const line of inquiryLines) {
    const match = line.match(PATTERNS.inquiry);
    if (match) {
      const bureau =
        /equifax|EQ|EFX/i.test(line) ? 'equifax' :
        /experian|EX|EXP/i.test(line) ? 'experian' :
        /transunion|TU/i.test(line) ? 'transunion' : 'unknown';

      inquiries.push({
        inquiringCompany: normalizeCreditorName(match[1]),
        dateOfInquiry: match[2],
        bureau,
        rawLine: line,
      });
    }
  }

  const parseConfidence = accounts.length > 0
    ? accounts.reduce((sum, a) => sum + a.confidence, 0) / accounts.length
    : 0;

  return {
    accounts,
    inquiries,
    personalInfo,
    parseConfidence,
    rawMatchCount: accounts.length + inquiries.length,
  };
}
```

function chunkText(fullText: string, maxChunkTokens = 3500): string[] {
  // Approximate: 1 token ≈ 4 chars for English credit report text
  const maxChars = maxChunkTokens * 4;
  const chunks: string[] = [];

  if (fullText.length <= maxChars) {
    return [fullText];
  }

  // Split on section headers or double newlines, respect maxChars
  const segments = fullText.split(/\n{2,}|---PAGE BREAK---|(?=\n[A-Z]{3,})/);
  let current = '';

  for (const seg of segments) {
    if ((current + seg).length > maxChars && current.length > 0) {
      chunks.push(current);
      current = seg;
    } else {
      current += (current ? '\n\n' : '') + seg;
    }
  }

  if (current) chunks.push(current);
  return chunks;
}

```typescript
export function validateAndEnrich(
  aiAccounts: AIEnhancedAccount[]
): ValidatedDisputeItem[] {
  const items: ValidatedDisputeItem[] = [];

  for (const account of aiAccounts) {
    const warnings: string[] = [];
    let needsReview = account.needsUserReview;

    // ── DATE SANITY CHECKS ──────────────────────────────────────
    if (account.dateClosed && account.dateOpened) {
      const closed = parseReportDate(account.dateClosed);
      const opened = parseReportDate(account.dateOpened);
      if (closed && opened && closed < opened) {
        warnings.push('Close date is before open date — please verify');
        needsReview = true;
      }
    }

    // ── 7-YEAR CLOCK CHECK ──────────────────────────────────────
    const now = new Date();
    if (account.dateOfFirstDelinquency) {
      const dofd = parseReportDate(account.dateOfFirstDelinquency);
      if (dofd) {
        const ageYears = (now.getTime() - dofd.getTime()) / (365.25 * 24 * 3600 * 1000);
        if (ageYears >= 7) {
          warnings.push(
            `This item appears to be ${ageYears.toFixed(1)} years old — ` +
            `may be past the 7-year FCRA reporting limit. Verify DOFD.`
          );
          needsReview = true;
        }
      }
    }

    // ── BALANCE SANITY ──────────────────────────────────────────
    if (account.balance && account.creditLimit &&
        account.balance > account.creditLimit * 2) {
      warnings.push('Balance significantly exceeds credit limit — may indicate re-aging');
    }

    // ── REQUIRED FIELDS CHECK ───────────────────────────────────
    if (!account.accountName || account.accountName.trim().length < 2) {
      warnings.push('Account name missing or too short — flagged for review');
      needsReview = true;
    }

    // ── BUREAU NORMALIZATION ────────────────────────────────────
    const bureauSet = new Set(account.bureaus.map(b => b.toLowerCase()));
    const validBureaus = ['equifax', 'experian', 'transunion'];
    const filteredBureaus = [...bureauSet].filter(b => validBureaus.includes(b));
    if (filteredBureaus.length === 0) filteredBureaus.push('equifax');

    const primaryBureau: 'equifax' | 'experian' | 'transunion' | 'all' =
      filteredBureaus.length === 3 ? 'all' :
      (filteredBureaus[0] as 'equifax' | 'experian' | 'transunion');

    // ── SCORING ─────────────────────────────────────────────────
    const { deletabilityScore, urgencyScore } = scoreItem(account);

    items.push({
      id: generateId(),
      accountName: account.accountName?.trim() || 'Unknown Account',
      accountNumber: account.accountNumber || '',
      balance: account.balance || 0,
      dateOpened: account.dateOpened || '',
      dateClosed: account.dateClosed || '',
      dateReported: account.dateReported || '',
      dateOfFirstDelinquency: account.dateOfFirstDelinquency || '',
      dateLastActive: account.dateLastActive || '',
      status: account.status || 'Unknown',
      itemType: (account.itemType as DisputeItemType) || 'unknown',
      creditorName: account.creditorName || account.accountName || '',
      creditorAddress: account.creditorAddress || undefined,
      originalCreditor: account.originalCreditor || undefined,
      bureaus: filteredBureaus,
      bureau: primaryBureau,
      monthlyPayment: account.monthlyPayment,
      creditLimit: account.creditLimit,
      paymentHistory: account.paymentHistory || undefined,
      remarks: account.remarks || undefined,
      validationWarnings: warnings,
      needsUserReview: needsReview,
      reviewReason: account.reviewReason,
      aiConfidence: account.aiConfidence,
      deletabilityScore,
      urgencyScore,
      // AutoPilot defaults (not yet disputed)
      disputePassNumber: 0,
      escalationLevel: 0,
      status_dispute: 'queued',
      holdDays: 60,
      assignedLetterIds: [],
      userNotes: [],
      aiNotes: warnings.length > 0
        ? ['Validation warnings: ' + warnings.join('; ')]
        : [],
    });
  }

  // Remove exact duplicates (same creditor + same balance)
  return deduplicateItems(items);
}

function deduplicateItems(items: ValidatedDisputeItem[]): ValidatedDisputeItem[] {
  const seen = new Set<string>();
  return items.filter(item => {
    const key = `${item.accountName.toLowerCase()}|${item.balance}|${item.bureau}`;
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
}

function parseReportDate(dateStr: string): Date | null {
  if (!dateStr) return null;
  // Try MM/YYYY
  const mmyyyy = dateStr.match(/^(\d{1,2})\/(\d{4})$/);
  if (mmyyyy) return new Date(parseInt(mmyyyy[2]), parseInt(mmyyyy[1]) - 1, 1);
  // Try MM/DD/YYYY
  const mmddyyyy = dateStr.match(/^(\d{1,2})\/(\d{1,2})\/(\d{4})$/);
  if (mmddyyyy) return new Date(parseInt(mmddyyyy[3]), parseInt(mmddyyyy[1]) - 1, parseInt(mmddyyyy[2]));
  return null;
}

function generateId(): string {
  return 'item_' + Date.now() + '_' + Math.random().toString(36).substring(2, 9);
}
```

```typescript
  pdfBuffer?: ArrayBuffer;

  success: boolean;
  items: ValidatedDisputeItem[];
  totalFound: number;
  needsReviewCount: number;
  warnings: string[];
  parseMethod: 'ai_full' | 'ai_partial_heuristic' | 'heuristic_only';

  processingTimeMs: number;
}

export async function parseCreditReport(
  options: ParseCreditReportOptions,
  aiRouter: AIRouter
): Promise<ParseCreditReportResult> {

  const startTime = Date.now();
  const warnings: string[] = [];

  options.onProgress?.(5, 'Acquiring report text...');

  // ── LAYER 1: TEXT ACQUISITION ─────────────────────────────────────
  let acquired;
  try {
    if (options.source === 'pdf_buffer' && options.pdfBuffer) {
      acquired = await acquireFromPDFBuffer(options.pdfBuffer);
    } else if (options.source === 'paste' && options.pasteText) {
      acquired = await acquireFromPaste(options.pasteText);
    } else if (options.source === 'file_path' && options.filePath) {
      acquired = await acquireFromFilePath(options.filePath);
    } else {
      throw new Error('No valid input source provided');
    }
  } catch (err) {
    return {
      success: false,
      items: [],
      totalFound: 0,
      needsReviewCount: 0,
      warnings: [(err as Error).message],
      parseMethod: 'heuristic_only',
      rawTextPreview: '',
      processingTimeMs: Date.now() - startTime,
    };
  }

  if (acquired.warnings.length > 0) warnings.push(...acquired.warnings);

  options.onProgress?.(15, 'Normalizing text...');

  // ── LAYER 2: NORMALIZATION ────────────────────────────────────────
  const normalized = normalizeText(acquired);

  options.onProgress?.(25, 'Running structural analysis...');

  // ── LAYER 3: HEURISTIC PRE-PARSE ─────────────────────────────────
  const heuristic = heuristicParse(normalized);

  options.onProgress?.(35, `Found ${heuristic.rawMatchCount} potential items via structural analysis. Running AI enhancement...`);

  // ── LAYER 4: AI ENHANCEMENT ───────────────────────────────────────
  let aiAccounts: AIEnhancedAccount[] = [];
  let parseMethod: ParseCreditReportResult['parseMethod'] = 'heuristic_only';

  try {
    aiAccounts = await aiEnhanceParse(
      normalized,
      heuristic,
      aiRouter,
      (progress, msg) => options.onProgress?.(35 + Math.round(progress * 0.5), msg)
    );
    parseMethod = aiAccounts.length > 0 ? 'ai_full' : 'ai_partial_heuristic';
  } catch (aiErr) {
    warnings.push(
      'AI enhancement failed — using structural parser only. ' +
      'Results may be incomplete. Error: ' + (aiErr as Error).message
    );
    parseMethod = 'heuristic_only';
    // Fall through to validation with heuristic data only
  }

  options.onProgress?.(88, 'Validating and enriching results...');

  // ── LAYER 5: VALIDATION + ENRICHMENT ────────────────────────────
  // If AI found nothing, use heuristic data directly
  const sourceAccounts = aiAccounts.length > 0
    ? aiAccounts
    : heuristic.accounts.map(h => ({
        ...h,
        aiConfidence: h.confidence,
        needsUserReview: true,
        reviewReason: 'Parsed by fallback structural parser — AI unavailable',
        creditLimit: null,
        monthlyPayment: null,
        originalCreditor: null,
        paymentHistory: null,
      })) as any[];

  const items = validateAndEnrich(sourceAccounts);

  options.onProgress?.(95, `Found ${items.length} dispute items. Building preview...`);

  const rawTextPreview = normalized.fullText.substring(0, 2000);
  const needsReviewCount = items.filter(i => i.needsUserReview).length;

  options.onProgress?.(100, 'Complete.');

  return {
    success: true,
    items,
    totalFound: items.length,
    needsReviewCount,
    warnings,
    parseMethod,
    rawTextPreview,
    processingTimeMs: Date.now() - startTime,
  };
}
```

```javascript
// ── PASTE TEXT SANITIZATION (shared helper) ────────────────────────
function sanitizePasteText(raw) {
  let text = raw;

  // Normalize line endings
  text = text.replace(/\r\n/g, '\n').replace(/\r/g, '\n');

  // Strip null bytes and other control chars (keep \n, \t)
  text = text.replace(/[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]/g, '');

  // NFKC normalization (Node.js has String.prototype.normalize)
  text = text.normalize('NFKC');

  // Remove non-printable Unicode categories
  text = text.replace(/\p{Cf}/gu, ''); // Format characters

  return text;
}
```

```typescript
export type AITask = 'parse' | 'letter' | 'analyze' | 'score' | 'image_analyze';

export interface AICompletionOptions {
  task: AITask;
  system: string;
  user: string;
  maxTokens?: number;
  temperature?: number;
  responseFormat?: 'text' | 'json_object';
  imageBase64?: string;
  imageMimeType?: string;
}

export interface AICompletionResult {
  text: string;
  provider: string;
  tokensUsed?: number;
  durationMs: number;
}

// Provider preference per task
const TASK_PROVIDER_ORDER: Record<AITask, string[]> = {
  parse:         ['gemini', 'openrouter', 'groq'], // Gemini has largest context window
  letter:        ['groq',   'openrouter', 'gemini'],// Groq fastest for letter gen
  analyze:       ['gemini', 'groq',       'openrouter'],
  score:         ['groq',   'gemini',     'openrouter'],
  image_analyze: ['gemini', 'openrouter', 'groq'],  // Gemini best for vision
};

export class AIRouter {
  private currentProviderIndex: Record<AITask, number> = {
    parse: 0,
    letter: 0,
    analyze: 0,
    score: 0,
    image_analyze: 0,
  };

  constructor(private keyService: SecureKeyService) {}

  async complete(options: AICompletionOptions): Promise<AICompletionResult> {
    const task = options.task;
    const providers = TASK_PROVIDER_ORDER[task];

    let lastError: Error | null = null;

    for (let attempt = 0; attempt < providers.length; attempt++) {
      const providerIdx =
        (this.currentProviderIndex[task] + attempt) % providers.length;
      const providerName = providers[providerIdx];

      try {
        const result = await this.callProvider(providerName, options);
        // Success — reset provider index for this task
        this.currentProviderIndex[task] = providerIdx;
        return result;
      } catch (err) {
        lastError = err as Error;
        console.warn(`[AIRouter] ${providerName} failed for task "${task}":`, err);
        // Continue to next provider
      }
    }

    throw new Error(
      `All AI providers failed for task "${task}". ` +
      `Last error: ${lastError?.message}. ` +
      `Please check your API keys in Settings.`
    );
  }

  async switchProvider(task?: AITask): Promise<void> {
    // Rotate to next provider for specified task (or all tasks)
    if (task) {
      const providers = TASK_PROVIDER_ORDER[task];
      this.currentProviderIndex[task] =
        (this.currentProviderIndex[task] + 1) % providers.length;
    } else {
      for (const t of Object.keys(this.currentProviderIndex) as AITask[]) {
        const providers = TASK_PROVIDER_ORDER[t];
        this.currentProviderIndex[t] =
          (this.currentProviderIndex[t] + 1) % providers.length;
      }
    }
  }

  private async callProvider(
    providerName: string,
    options: AICompletionOptions
  ): Promise<AICompletionResult> {
    const startTime = Date.now();

    // Get API key from secure storage
    const apiKey = await this.keyService.getKey(providerName);
    if (!apiKey) {
      throw new Error(
        `No API key configured for ${providerName}. ` +
        `Please add your ${providerName} API key in Settings.`
      );
    }

    switch (providerName) {
      case 'gemini':
        return this.callGemini(apiKey, options, startTime);
      case 'groq':
        return this.callGroq(apiKey, options, startTime);
      case 'openrouter':
        return this.callOpenRouter(apiKey, options, startTime);
      default:
        throw new Error('Unknown provider: ' + providerName);
    }
  }

  private async callGemini(
    apiKey: string,
    options: AICompletionOptions,
    startTime: number
  ): Promise<AICompletionResult> {
    const model = options.task === 'parse'
      ? 'gemini-2.0-flash-exp'   // Large context for parsing
      : 'gemini-1.5-flash';

    const parts: any[] = [];

    if (options.imageBase64 && options.imageMimeType) {
      parts.push({
        inline_data: {
          mime_type: options.imageMimeType,
          data: options.imageBase64,
        },
      });
    }

    parts.push({ text: options.user });

    const body: any = {
      contents: [{ parts }],
      systemInstruction: { parts: [{ text: options.system }] },
      generationConfig: {
        maxOutputTokens: options.maxTokens || 4000,
        temperature: options.temperature ?? 0.3,
        responseMimeType: options.responseFormat === 'json_object'
          ? 'application/json'
          : 'text/plain',
      },
      safetySettings: [
        { category: 'HARM_CATEGORY_HARASSMENT', threshold: 'BLOCK_NONE' },
        { category: 'HARM_CATEGORY_DANGEROUS_CONTENT', threshold: 'BLOCK_NONE' },
      ],
    };

    const response = await fetch(
      `https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent?key=${apiKey}`,
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(body),
      }
    );

    if (!response.ok) {
      const errText = await response.text();
      throw new Error(`Gemini API error ${response.status}: ${errText}`);
    }

    const data = await response.json();
    const text = data.candidates?.[0]?.content?.parts?.[0]?.text;

    if (!text) throw new Error('Gemini returned empty response');

    return {
      text,
      provider: 'gemini',
      tokensUsed: data.usageMetadata?.totalTokenCount,
      durationMs: Date.now() - startTime,
    };
  }

  private async callGroq(
    apiKey: string,
    options: AICompletionOptions,
    startTime: number
  ): Promise<AICompletionResult> {
    const body = {
      model: 'llama-3.3-70b-versatile',
      messages: [
        { role: 'system', content: options.system },
        { role: 'user', content: options.user },
      ],
      max_tokens: options.maxTokens || 4000,
      temperature: options.temperature ?? 0.3,
      response_format: options.responseFormat === 'json_object'
        ? { type: 'json_object' }
        : { type: 'text' },
    };

    const response = await fetch('https://api.groq.com/openai/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer ' + apiKey,
      },
      body: JSON.stringify(body),
    });

    if (!response.ok) {
      const errText = await response.text();
      throw new Error(`Groq API error ${response.status}: ${errText}`);
    }

    const data = await response.json();
    const text = data.choices?.[0]?.message?.content;

    if (!text) throw new Error('Groq returned empty response');

    return {
      text,
      provider: 'groq',
      tokensUsed: data.usage?.total_tokens,
      durationMs: Date.now() - startTime,
    };
  }

  private async callOpenRouter(
    apiKey: string,
    options: AICompletionOptions,
    startTime: number
  ): Promise<AICompletionResult> {
    const body = {
      model: 'anthropic/claude-3.5-sonnet',
      messages: [
        { role: 'system', content: options.system },
        { role: 'user', content: options.user },
      ],
      max_tokens: options.maxTokens || 4000,
      temperature: options.temperature ?? 0.3,
    };

    const response = await fetch('https://openrouter.ai/api/v1/chat/completions', {
      method: 'POST',

      text,
      provider: 'openrouter',

    };
  }
```

```javascript
function safeRelativePath(base, relativePath) {
  if (!relativePath || typeof relativePath !== 'string') {
    throw new Error('Invalid path: must be a non-empty string');
  }
  // Normalize and resolve
  const normalized = path.normalize(relativePath).replace(/^(\.\.[/\\])+/, '');
  const fullPath = path.resolve(base, normalized);

  // Must remain within base directory
  if (!fullPath.startsWith(path.resolve(base))) {
    throw new Error('Path traversal detected: ' + relativePath);
  }

  return fullPath;
}
```
